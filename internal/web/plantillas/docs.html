MCP

Para que un modelo consulte el Boletín como una herramienta más. {{if .ConMCP}} Habla JSON-RPC 2.0 en POST {{.Base}}/mcp{{if .TokenMCP}}, con Authorization: Bearer{{end}}, y el mismo binario también lo habla por entrada estándar, para un cliente local: {{else}} En esta instancia el endpoint HTTP está apagado (NOTARUM_SIN_MCP), pero el binario lo habla igual por entrada estándar, que es como lo usa un cliente local: {{end}} 

{
  "mcpServers": {
    "notarum": {
      "command": "notarum",
      "args": ["mcp", "--almacen", "sqlite", "--db", "/ruta/notarum.db"]
    }
  }
}

Errores

Todo error viene como JSON y dice de quién es la culpa, para que sepas a quién mirar antes de empezar a buscar. 

{ "error": "el Boletín Oficial no devolvió lo esperado", "origen": "sitio" }
sitioel Boletín Oficial no contestó o cambió de forma
notarumfalló algo de este servicio
pedidoel pedido está mal armado

Un día sin edición devuelve 404 con "sin_edicion": true. No es una falla: es un feriado.
